#  Mass++4 Quick Manual

A quick manual for [Mass++4](https://mspp.ninja/), an open-source viewer for
mass spectrometry data. It describes the next release of Mass++4.

##  Contents

| No. | Chapter | What you learn |
| --- | --- | --- |
| 00 | [Current Limitations](00_Current_Limitations.md) | What Mass++4 cannot do yet |
| 01 | [Installation](01_Installation.md) | Downloading and installing Mass++4 on Windows, macOS and Linux |
| 02 | [Opening an mzML file](02_Opening_mzML.md) | Opening a file, drawing chromatograms and spectra, zooming, panning, the heatmap and the 3D view |
| 03 | [TIC, XIC and Spectrum Navigation](03_TIC_XIC_and_Spectrum_Navigation.md) | Using the TIC, creating XICs, and moving between spectra |
| 04 | [Peak Filtering with One Concrete Formula](04_Peak_Filtering_with_one_concrete_formula.md) | Finding MS/MS spectra that contain an ion calculated from a formula |
| 05 | [Peak Picking](05_Peak_Picking.md) | How peaks are picked, peak labels, and saving peak lists |
| 06 | [SVG Export](06_SVG_Export.md) | Saving spectra and chromatograms as SVG figures |
| 07 | [Python MS Data Link Example](07_Python_MS_data_link_example.md) | Exchanging spectra between Mass++4 and Python through the API |

If you are new to Mass++4, read the chapters from 00 to 02 first. The other
chapters can be read in any order.
